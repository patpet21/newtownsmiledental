# Cinematic Project Showcase & Portfolio Guide

Implemented: 2026-10-17

## Homepage
Replaces the flat horizontal work rail with a five-position 3D-perspective gallery inspired by the user-provided Tuscany villa carousel screenshot.

- Center project in focus; two angled and dimmed neighbors each side on desktop; one each side on mobile.
- Drag/swipe horizontally, click an adjacent card, use left/right arrows, select a progress dot, or use keyboard ArrowLeft/ArrowRight/Home/End.
- Center selection opens that project's existing case-study route.
- Active title, number and progress update together.
- Uses eight existing original project cover SVG images. They are **concept illustrations**, not screenshots.
- CSS perspective only; no new packages, hosting service, media subscription or GitHub Actions.

## Portfolio guide (no AI)
- Fixed, compact "Explore with me" chat-like guide available on all pages.
- Scripted, deterministic keywords and shortcut chips for PrivacyGate, PrivateStone, PropertyDEX, websites, operations, other projects, About, Services and Contact.
- Replies link to relevant portfolio pages. No generative AI, chatbot API, network requests, persistence or human operator.
- Contact enquiries still go through the pre-existing contact form.
- Escape closes the panel, and reduced-motion preferences are respected.
